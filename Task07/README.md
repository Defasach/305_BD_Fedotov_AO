# Лабораторная работа 7. Сценарии PHP для работы с базой данных СТО

## Описание
Данный проект представляет собой систему учёта услуг станции технического обслуживания автомобилей, реализованную в двух вариантах:
1. **Консольное приложение** (`task7_cli.php`) - для работы через командную строку
2. **Веб-приложение** (`index.php`) - для работы через браузер

## Структура проекта
```
Task07/
├── sto.db              # База данных SQLite с информацией о СТО
├── task7_cli.php       # Консольное PHP-приложение
├── index.php           # Веб-приложение
└── README.md           # Документация
```

## База данных

База данных `sto.db` содержит следующие таблицы:
- **Masters** - мастера СТО (id, ФИО, телефон, процент зарплаты, даты приёма/увольнения)
- **Services** - услуги (id, название, длительность, стоимость)
- **Appointments** - записи на обслуживание (id, мастер, клиент, автомобиль, дата/время, статус)
- **AppointmentServices** - связь записей и услуг (выполненные работы)

## Консольное приложение (task7_cli.php)

### Функциональность
- Подключение к базе данных через PDO
- Вывод списка всех мастеров из базы данных
- Возможность фильтрации услуг по номеру мастера
- Валидация введённого номера мастера
- Вывод таблицы с псевдографикой (Unicode box-drawing characters)
- Сортировка по фамилии мастера и дате выполнения работы

### Запуск

## Технические требования

### Минимальные требования
- PHP 7.4 или выше
- SQLite3 PDO extension
- Терминал с поддержкой UTF-8 (для консольного приложения)
- Веб-браузер (для веб-приложения)

### Используемые технологии
- **PDO** (PHP Data Objects) для работы с БД
- **SQLite** в качестве СУБД
- **Prepared Statements** для безопасности
- **HTML5** и **CSS3** для веб-интерфейса
- **Unicode box-drawing** для псевдографики

## Безопасность

Оба приложения реализуют следующие меры безопасности:
1. **Подготовленные запросы** - защита от SQL-инъекций
2. **Валидация ввода** - проверка типов и диапазонов значений
3. **Экранирование вывода** - защита от XSS-атак (веб-версия)
4. **Обработка ошибок** - корректное отображение ошибок без раскрытия внутренней информации

## SQL-запрос

Основной запрос для получения данных об услугах:
```sql
SELECT 
    m.id AS master_id,
    m.full_name AS master_name,
    DATE(aps.completed_at) AS work_date,
    s.name AS service_name,
    s.price AS service_price
FROM AppointmentServices aps
INNER JOIN Appointments a ON aps.appointment_id = a.id
INNER JOIN Masters m ON a.master_id = m.id
INNER JOIN Services s ON aps.service_id = s.id
WHERE aps.is_completed = 1
  AND m.id = :master_id  -- опционально, для фильтрации
ORDER BY m.full_name, aps.completed_at
```
