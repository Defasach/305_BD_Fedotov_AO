# Task05 - Нормализация реляционной базы данных

## Описание
Лабораторная работа по нормализации базы данных movies_rating до третьей нормальной формы (3НФ) с добавлением ограничений целостности данных.

## Структура базы данных

### Таблицы

#### Справочники:
1. **occupations** - профессии пользователей
2. **genres** - жанры фильмов

#### Основные таблицы:
3. **users** - пользователи системы
4. **movies** - фильмы
5. **movie_genres** - связь фильмов и жанров (многие-ко-многим)
6. **ratings** - оценки фильмов пользователями
7. **tags** - теги к фильмам от пользователей

### Ограничения целостности

✅ **Реализованные ограничения:**
- `users.email UNIQUE` - нет двух пользователей с одинаковым email
- `users.gender CHECK IN ('male', 'female')` - пол только мужской или женский
- `ratings.rating CHECK (rating >= 0 AND rating <= 5)` - рейтинг от 0 до 5 включительно
- `ratings.movie_id ON DELETE RESTRICT` - нельзя удалить фильм, если есть отзывы
- `tags.movie_id ON DELETE RESTRICT` - нельзя удалить фильм, если есть теги
- `ratings.user_id ON DELETE CASCADE` - при удалении пользователя удаляются его оценки
- `tags.user_id ON DELETE CASCADE` - при удалении пользователя удаляются его теги

### Индексы

Для ускорения поиска созданы индексы:
- `idx_users_name` - поиск по имени/фамилии пользователя
- `idx_movies_title` - поиск по названию фильма
- `idx_movies_year` - поиск по году выпуска фильма

## Использование

### Создание БД:
```bash
sqlite3 movies_rating.db < db_init.sql
```

### Добавление новых данных:
```bash
sqlite3 movies_rating.db < data_add.sql
```

### Включение проверки внешних ключей:
```sql
PRAGMA foreign_keys = ON;
```
