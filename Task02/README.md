# Лабораторная работа 2. Подготовка скриптов для создания таблиц и добавления данных

## Описание

Эта работа реализует процесс ETL (Extract, Transform, Load) для переноса исходных данных в базу данных SQLite. Утилита автоматически генерирует SQL-скрипт для создания таблиц и загрузки данных.

## Файлы проекта

- **make_db_init.py** - Python-утилита для генерации SQL-скрипта из исходных данных
- **db_init.bat** - кроссплатформенный shell-скрипт для запуска генерации и загрузки БД
- **db_init.sql** - генерируемый SQL-скрипт (создаётся при запуске)
- **movies_rating.db** - создаваемая база данных SQLite (создаётся при запуске)
- Исходные данные: movies.csv, ratings.csv, tags.csv, users.txt, genres.txt, occupation.txt

## Требования к окружению

Для корректной работы скрипта `db_init.bat` необходимо наличие:

### Обязательные:
1. **Python 3.6+** - интерпретатор Python версии 3 и выше
   - На Ubuntu/Debian: `sudo apt install python3`
   - На macOS: `brew install python3`
   - На Windows: скачать с https://www.python.org/downloads/

2. **SQLite 3** - встраиваемая система управления базами данных
   - На Ubuntu/Debian: `sudo apt install sqlite3`
   - На macOS: поставляется стандартно, или `brew install sqlite3`
   - На Windows: скачать с https://www.sqlite.org/download.html или использовать встроенную версию

3. **Bash shell** - командный интерпретатор
   - На Linux/macOS: предустановлен
   - На Windows: установить Git Bash, WSL или использовать PowerShell с переводом команд

### Требования к файловой системе:
- Исходные файлы данных должны находиться в той же директории, что и скрипты
- Права на чтение исходных файлов
- Права на запись в директорию для создания db_init.sql и movies_rating.db

## Использование

### Шаг 1: Проверка окружения

Убедитесь, что установлены необходимые компоненты:

```bash
python3 --version
sqlite3 --version
```

### Шаг 2: Запуск скрипта инициализации

Переходите в директорию Task02 и запустите скрипт:

```bash
chmod +x db_init.bat
./db_init.bat
```

Или напрямую:

```bash
python3 make_db_init.py
sqlite3 movies_rating.db < db_init.sql
```

### Шаг 3: Проверка результата

После успешного выполнения скрипта будут созданы:
- **db_init.sql** - SQL-скрипт с командами CREATE TABLE и INSERT
- **movies_rating.db** - файл базы данных SQLite

Проверить содержимое БД:

```bash
sqlite3 movies_rating.db
> .tables
> SELECT COUNT(*) FROM movies;
> SELECT COUNT(*) FROM ratings;
> SELECT COUNT(*) FROM tags;
> SELECT COUNT(*) FROM users;
> .quit
```

## Структура создаваемой базы данных

### Таблица movies
- **id** (INTEGER, PRIMARY KEY) - уникальный идентификатор фильма
- **title** (TEXT NOT NULL) - название фильма
- **year** (INTEGER) - год выпуска
- **genres** (TEXT) - жанры (разделены "|")

### Таблица ratings
- **id** (INTEGER, PRIMARY KEY) - уникальный идентификатор оценки
- **user_id** (INTEGER NOT NULL) - идентификатор пользователя
- **movie_id** (INTEGER NOT NULL) - идентификатор фильма
- **rating** (REAL NOT NULL) - оценка (0.5-5.0)
- **timestamp** (INTEGER NOT NULL) - временная метка Unix

### Таблица tags
- **id** (INTEGER, PRIMARY KEY) - уникальный идентификатор тега
- **user_id** (INTEGER NOT NULL) - идентификатор пользователя
- **movie_id** (INTEGER NOT NULL) - идентификатор фильма
- **tag** (TEXT NOT NULL) - текст тега
- **timestamp** (INTEGER NOT NULL) - временная метка Unix

### Таблица users
- **id** (INTEGER, PRIMARY KEY) - уникальный идентификатор пользователя
- **name** (TEXT NOT NULL) - имя пользователя
- **email** (TEXT) - электронная почта
- **gender** (TEXT) - пол
- **register_date** (TEXT) - дата регистрации (YYYY-MM-DD)
- **occupation** (TEXT) - профессия

## Особенности реализации

1. **Кроссплатформенность**: Скрипт работает на Linux, macOS и Windows (при наличии необходимых компонентов)

2. **Обработка данных**: 
   - Год автоматически извлекается из названия фильма в скобках (YYYY)
   - ID для таблиц ratings и tags генерируются последовательно
   - Все строковые значения экранируются для безопасности SQL

3. **Переиспользуемость**: При повторном запуске скрипта старые таблицы удаляются и создаются заново

4. **Кодировка**: Все файлы используют кодировку UTF-8

## Возможные ошибки и решения

| Ошибка | Решение |
|--------|---------|
| `python3: command not found` | Установите Python 3 |
| `sqlite3: command not found` | Установите SQLite 3 |
| `Permission denied` | Выполните `chmod +x db_init.bat` |
| `No such file or directory` | Проверьте, что исходные файлы находятся в той же директории |
| Файл уже существует | БД будет перезаписана (старые таблицы удалены) |
