# Лабораторная работа 8. Сценарии PHP. Создание веб-формы для ввода данных в БД

## Описание

Веб-приложение для управления станцией технического обслуживания (СТО) автомобилей. Система позволяет:
- Регистрировать мастеров и привязывать к ним услуги, которые они могут выполнять
- Управлять графиком работы мастеров
- Создавать предварительные записи клиентов к мастерам

## Структура проекта

```
Task08/
├── data/
│   └── sto.db              # База данных SQLite
└── public/                 # Корень веб-сайта
    ├── index.php           # Главная страница с меню
    ├── add_master.php      # Форма добавления мастера
    ├── add_schedule.php    # Форма управления графиком
    ├── add_appointment.php # Форма записи к мастеру
    ├── get_masters.php     # API: получение мастеров по услуге
    ├── get_available_times.php # API: доступные временные слоты
    ├── config.php          # Конфигурация подключения к БД
    └── style.css           # Стили оформления
```

## Структура базы данных

### Таблица `services` - Услуги СТО
- `id` - уникальный идентификатор
- `name` - название услуги
- `description` - описание
- `duration` - длительность в минутах

### Таблица `masters` - Мастера
- `id` - уникальный идентификатор
- `name` - ФИО мастера
- `phone` - телефон
- `email` - электронная почта

### Таблица `master_services` - Связь мастеров и услуг
- `id` - уникальный идентификатор
- `master_id` - ID мастера
- `service_id` - ID услуги

### Таблица `schedules` - График работы мастеров
- `id` - уникальный идентификатор
- `master_id` - ID мастера
- `day_of_week` - день недели (1-7, где 1 = понедельник)
- `start_time` - время начала работы
- `end_time` - время окончания работы

### Таблица `appointments` - Записи клиентов
- `id` - уникальный идентификатор
- `master_id` - ID мастера
- `service_id` - ID услуги
- `client_name` - имя клиента
- `client_phone` - телефон клиента
- `appointment_date` - дата записи
- `appointment_time` - время записи
- `status` - статус записи (по умолчанию 'scheduled')

## Функциональность

### 1. Добавление мастера (add_master.php)
- Ввод данных мастера (ФИО, телефон, email)
- Выбор услуг, которые может выполнять мастер (множественный выбор)
- Валидация данных
- Транзакционное сохранение (мастер + привязка услуг)

### 2. График работы (add_schedule.php)
- Выбор мастера из списка
- Выбор дня недели
- Указание времени начала и окончания работы
- Просмотр текущих расписаний всех мастеров

### 3. Запись к мастеру (add_appointment.php)
**Динамическое взаимодействие:**
1. Клиент выбирает услугу
2. Система загружает только тех мастеров, которые выполняют эту услугу (AJAX)
3. После выбора мастера разблокируется выбор даты
4. При выборе даты система:
   - Определяет день недели
   - Проверяет график работы мастера
   - Получает занятые временные слоты
   - Формирует список доступного времени (интервал 30 минут)
5. Клиент заполняет контактные данные и отправляет форму

## Безопасность

- Использование подготовленных запросов (Prepared Statements) для защиты от SQL-инъекций
- Экранирование вывода с помощью `htmlspecialchars()` для защиты от XSS
- Валидация данных на стороне сервера
- Использование транзакций для обеспечения целостности данных

## Запуск проекта

1. Убедитесь, что установлены PHP и SQLite:
   ```bash
   php -v
   sqlite3 --version
   ```

2. Перейдите в директорию public:
   ```bash
   cd Task08/public
   ```

3. Запустите встроенный веб-сервер PHP:
   ```bash
   php -S localhost:8000
   ```

4. Откройте браузер и перейдите по адресу:
   ```
   http://localhost:8000
   ```
