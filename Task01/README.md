# Структура файлов данных для проекта MovieLens

## Описание

Этот каталог содержит исходные данные для работы с системой рецензирования фильмов. Данные организованы в формате CSV и текстовых файлов с разделителями.

## Содержимое файлов

### movies.csv
Информация о фильмах в CSV формате.
- **Формат**: CSV (запятая как разделитель)
- **Колонки**:
  - `movieId` - уникальный идентификатор фильма (числовой)
  - `title` - название фильма (текст)
  - `genres` - жанры фильма через разделитель `|` (текст)
- **Пример**: `1,Toy Story (1995),Adventure|Animation|Children|Comedy|Fantasy`

### ratings.csv
Оценки фильмов пользователями в CSV формате.
- **Формат**: CSV (запятая как разделитель)
- **Колонки**:
  - `userId` - идентификатор пользователя (числовой)
  - `movieId` - идентификатор фильма (числовой)
  - `rating` - оценка фильма (число с плавающей точкой, 0.5-5.0)
  - `timestamp` - временная метка оценки в формате Unix timestamp (числовой)
- **Пример**: `1,1,4.0,964982703`
- **Объём**: 18773 строк (+ 1 строка заголовка)

### tags.csv
Теги/отзывы пользователей о фильмах в CSV формате.
- **Формат**: CSV (запятая как разделитель)
- **Колонки**:
  - `userId` - идентификатор пользователя (числовой)
  - `movieId` - идентификатор фильма (числовой)
  - `tag` - текстовая метка/тег (текст)
  - `timestamp` - временная метка в формате Unix timestamp (числовой)
- **Пример**: `2,60756,funny,1445714994`

### users.txt
Информация о пользователях в текстовом формате с разделителем.
- **Формат**: Текстовый файл с разделителем `|` (pipe-separated)
- **Колонки**:
  - `id` - уникальный идентификатор пользователя (числовой)
  - `name` - имя пользователя (текст)
  - `email` - адрес электронной почты (текст)
  - `gender` - пол (male/female или другое)
  - `register_date` - дата регистрации в формате YYYY-MM-DD (текст)
  - `occupation` - профессия/род деятельности (текст)
- **Пример**: `1|Devonte Stamm|marianne.krajcik@bartoletti.com|male|2010-09-19|technician`

### genres.txt
Справочник доступных жанров.
- **Формат**: Текстовый файл, один жанр на строку
- **Содержание**: Полный список всех жанров, используемых в movies.csv
- **Жанры**:
  - Action, Adventure, Animation, Children's, Comedy, Crime, Documentary, Drama, Fantasy
  - Film-Noir, Horror, Musical, Mystery, Romance, Sci-Fi, Thriller, War, Western

### occupation.txt
Справочник доступных профессий.
- **Формат**: Текстовый файл, одна профессия на строку
- **Содержание**: Полный список всех профессий, используемых в users.txt
- **Профессии**: 
  - administrator, artist, doctor, educator, engineer, entertainment, executive, healthcare
  - homemaker, lawyer, librarian, marketing, none, other, programmer, retired
  - salesman, scientist, student, technician, writer

## Кодировка

Все файлы используют кодировку UTF-8.

## Использование

Эти файлы предназначены для загрузки в реляционную базу данных SQLite. Данные будут использоваться для создания таблиц:
- `movies` - информация о фильмах
- `ratings` - оценки пользователей
- `tags` - теги пользователей
- `users` - профили пользователей
